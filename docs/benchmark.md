# 既有测试摘要与证据边界

整理日期：2026-09-12。

本摘要记录项目创建前进行的一次本地测试，用于解释工作流设计。不是本 Skill 发布后的端到端测试，不是任何平台的总体成功率评估。

## 参照与方法

- 确定的 35 个 DOI，每个都有本地正文作为参照。
- 其中 31 篇有共 41 个已下载 SI 文件：32 PDF、5 MP4、3 DOCX、1 XLSX。
- 其余 4 篇不进入 SI 覆盖率分母：1 篇确认无独立 SI，3 篇未解决且由用户接受缺项。
- 参照集是用户已持有的文件集，不是独立证明过的官网全部附件全集。
- 两个工具分别尝试 35 个 DOI，共 70 项。
- 使用文件 SHA-256 或规范化全文匹配。规范化为 Unicode NFKC、casefold，并去除非单词字符；它是文档匹配指标，不代表逐图逐表的视觉一致性验证。
- 正文仅 DOI/标题匹配的候选单列。误收图片、审稿记录不增加 SI 覆盖。
- 测试取得并匹配成功的 SI 均为字节一致。

## 运行条件

`manuscript-harvest`：`--oa-only --no-proxy`，未配置联系邮箱或 API 密钥，`text_bearing_only: false`，最多 300 文件、单文件 80 MB、请求超时 12 秒、单项进程 60 秒上限、每主机约 3 秒请求间隔。

`SI-Merge`：只调用其 SI 发现与下载模块，使用普通 `requests` 回退路径，未测试机构浏览器、正文下载和合并阅读功能。单项进程 30 秒上限。保留转换前原始文件，DOCX/XLSX 即使转换失败也可参与文件匹配。

未上传本地论文，未使用科研通积分，也未修改原文献库。测试下载文件留在独立目录。

## 结果

| 对象 | 正文匹配 | 已知 SI 文件匹配 | 全部已知 SI 匹配的论文 |
|---|---:|---:|---:|
| manuscript-harvest | 3，另有 1 个身份候选 | 4/41 | 3/31 |
| SI-Merge | 未测试 | 21/41 | 16/31 |
| 两者 SI 结果合并 | 不适用 | 22/41 | 17/31 |

正文 3 个匹配包含字节一致或规范化全文一致；另 1 个候选 DOI、标题符合，但不能并入精确匹配数。

完成项累计下载子进程时间：`manuscript-harvest` 约 634 秒，`SI-Merge` 约 236 秒。合计约 14.5 分钟，不含安装、文件指纹提取、任务中断与恢复开销，不等于用户端总耗时。

## 观察到的失败

- SSL 连接错误、403、503、旧仓储链接 404、一次 60 秒超时。
- 前期小样本试跑中，文件数量上限先被图片占满，真正 SI 未取得；该现象不是本次 300 文件上限下所有失败的原因。
- SI-Merge 将一份 Peer Review File 下载为候选附件；人工核对后不计为 SI。
- 参照集中的 5 个 MP4 未被匹配。
- 8 项上游状态 JSON 解析遇到编码问题，因此按实际落盘文件评分，而非仅采信退出码或完成标签。

## 不能推导什么

不能推导这些项目在其他网络、版本、出版社分布、机构授权或完整 API 配置下也只有同样成功率。不能推导科研通能补齐所有缺项，或商业服务一定更贵。不能把“用户同意结束任务”计为“所有附件下载成功”。

原始私人文件与日志未公开，测试未固定公开的上游提交标识和完整环境锁文件，因此这里只是既有案例摘要，不是可独立复现的公开排行榜。后续公开基准应先固定版本与配置，选择可公开的 DOI 清单和可再分发样例，并记录网络、时间上限及人工介入。

## 设计启发

复用模块可以节省工作，但交付层还需要维护独立的身份、完整度、支出与请求状态。工具返回成功不能替代这些证据。
